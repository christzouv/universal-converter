# Universal Converter

Convert images, documents, videos and audio, build and sign PDFs, fill in forms and pull tables into Excel - all offline,
your files never leave your device. A free-to-use software tool for Windows, Mac and Android. Available in English, Greek, Spanish,
Italian, German, French, Portuguese, Russian, Arabic, Hebrew, Simplified Chinese, Japanese, Korean, Tamil, Afrikaans,
Yoruba and Hausa.

**Website:** https://christzouv.github.io/universal-converter/

**Windows:** run `Universal-Converter-Setup-x.y.exe`. The installer isn't code-signed yet, so Windows may show a SmartScreen
warning: choose "More info", then "Run anyway". The Microsoft Store version installs without the warning and updates through the Store.
The website links the [virus scan of the newest installer](https://christzouv.github.io/universal-converter/).

**Mac:** open the `.dmg` and drag Universal Converter into Applications. The app isn't signed by Apple, so the first time
macOS blocks it: open System Settings > Privacy & Security and click "Open Anyway".

**Android:** open the APK on your phone and allow the install when asked. English and Greek are built in; other languages
can be downloaded in the app's Settings.

Installed Windows and Mac copies check this page each time they start and offer new versions; the Android app checks about once a day.
