# Universal Converter

Convert images, documents, videos and audio, build and sign PDFs, fill in forms and pull tables into Excel - all offline,
your files never leave your device. A free-to-use software tool for Windows, Mac, Linux and Android, in 34 languages.

**Website:** https://getuniversalconverter.com/

The website links a virus scan of every download.

**Windows:** run `Universal-Converter-Setup-3.8.exe`. The installer isn't code-signed yet, so Windows may show a SmartScreen
warning: choose "More info", then "Run anyway". The Microsoft Store version installs without the warning and updates through the Store.
If Windows' Smart App Control blocks the app or its video part, use the Microsoft Store version: Windows trusts it.

**Mac:** open the `.dmg` and drag Universal Converter into Applications. The app isn't signed by Apple, so the first time
macOS blocks it: open System Settings > Privacy & Security and click "Open Anyway".

**Linux:** allow the AppImage to run as a program (Properties > Permissions, or `chmod +x Universal-Converter-3.8-x86_64.AppImage`)
and open it. Nothing to install; updates replace the file where it is.

**Android:** open the APK on your phone and allow the install when asked. All 34 languages are built in.

Installed Windows, Mac and Linux copies check this page each time they start and offer new versions; the Android app checks about once a day.
