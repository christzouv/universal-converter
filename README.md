# Universal Converter

Convert images, documents, videos and audio, build PDFs and pull tables into Excel - all offline,
your files never leave your computer.

**Download:** get the latest `Universal-Converter-Setup-x.y.z.exe` from
[Releases](https://github.com/christzouv/universal-converter/releases/latest) and run it
(Windows 10 and 11, 64-bit).

Installed copies check this page once a day and update themselves.
