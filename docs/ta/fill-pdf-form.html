PDF படிவத்தை நிரப்புதல்

நிரப்பக்கூடிய PDF படிவங்களிலும் சாதாரண PDF-களிலும் வேலை செய்யும்: படிவப் புலத்தைச் சொடுக்கி அதில் எழுதுங்கள், அல்லது பக்கத்தில் எங்கும் உரை, சரிக்குறிகள், பெருக்கல் குறிகள், தேதியைச் சேருங்கள். நிரப்பிய படிவம் எல்லா இடத்திலும் ஒரே மாதிரித் தெரியும் முடிந்த PDF ஆகச் சேமிக்கப்படும்.

Windows-க்குப் பதிவிறக்கு Microsoft Store-இலிருந்து பெறுக
இலவசம் · Windows 10, 11, 64-பிட் · வைரஸ் சோதனை அறிக்கைWindows பதிவிறக்கத்தையோ பயன்பாட்டையோ தடுக்கிறதா? Microsoft Store-இலிருந்து பெறுங்கள்: அதே இலவச பயன்பாடு, Windows அதை நம்புகிறது.
Mac-க்குப் பதிவிறக்கு Apple silicon, macOS 12 அல்லது புதியது
நிறுவுவது, புதுப்பிப்பது எப்படி
  1. பதிவிறக்கிய .dmg-ஐத் திறந்து Universal Converter-ஐ Applications-க்கு இழுக்கவும்.
  2. செயலியைத் திறக்கவும். Apple-ஆல் கையொப்பமிடப்படாததால் முதல் முறை macOS அதைத் தடுக்கும்: Done என்பதைக் கிளிக் செய்யவும்.
  3. System Settings > Privacy & Security என்பதைத் திறந்து, கீழே உருட்டி, Open Anyway என்பதைக் கிளிக் செய்து கடவுச்சொல்லை உள்ளிடவும். இதை ஒருமுறை மட்டுமே செய்ய வேண்டும்.

புதுப்பிப்புகள்: செயலி முதலில் திறக்கும்போது நீங்கள் அனுமதித்தால், ஒவ்வொரு முறை தொடங்கும்போதும் புதிய பதிப்புகளைச் சரிபார்த்து, அவற்றின் டிஜிட்டல் கையொப்பத்தை உறுதிசெய்து, நீங்கள் தேர்வுசெய்யும்போது நிறுவும்.

Android-க்குப் பதிவிறக்கு Android 10 அல்லது புதியது
நிறுவுவது, புதுப்பிப்பது எப்படி
  1. உங்கள் தொலைபேசியில் “Android-க்குப் பதிவிறக்கு” என்பதைத் தட்டவும்.
  2. பதிவிறக்கிய கோப்பைத் திறக்கவும். Android கேட்டால், உங்கள் உலாவி அல்லது கோப்பு மேலாளர் செயலிகளை நிறுவ அனுமதிக்கவும்.
  3. நிறுவு என்பதைத் தட்டவும்.

புதுப்பிப்புகள்: செயலி தோராயமாக நாளுக்கு ஒருமுறை சரிபார்த்து, புதிய பதிப்பு தயாரானதும் சொல்லும். அதை அதே வழியில் பதிவிறக்கி பழையதன் மேல் நிறுவவும்; உங்கள் அமைப்புகள் காக்கப்படும்.

இதை எப்படிச் செய்வது

  1. Universal Converter-ஐத் திறந்து, இடதுபுறம் கையொப்பம் என்பதைத் தேர்ந்தெடுக்கவும்.
  2. உங்கள் கோப்புகளை அல்லது ஒரு முழுக் கோப்புறையைச் சாளரத்திற்குள் இழுக்கவும், அல்லது “கோப்புகளைச் சேர்” என்பதைக் கிளிக் செய்யவும்.
  3. பக்கத்தைத் திற என்பதைச் சொடுக்கி, படிவப் புலங்களைச் சொடுக்கி நிரப்புங்கள், அல்லது உரை, தேதி அல்லது சரிக்குறியைத் தேர்ந்தெடுத்துப் பக்கத்தில் சொடுக்குங்கள்.
  4. முடிந்தது என்பதையும் பின்னர் கையொப்பமிடு பொத்தானையும் சொடுக்குங்கள். நிரப்பிய நகல் பெயர்_signed.pdf ஆகச் சேமிக்கப்படும்; மூலக் கோப்பு மாறாமல் இருக்கும்.

ஏன் இணையமின்றி?

Universal Converter உங்கள் சொந்தச் சாதனத்திலேயே வேலை செய்கிறது. உங்கள் கோப்புகள் தனிப்பட்டவையாக இருக்கும், பெரிய கோப்புகள் பிரச்சினையல்ல, இணைய இணைப்பு இல்லாமலும் இயங்கும்.
