Kadalasang nililimitahan ng mga form at email ang laki ng mga attachment. Kayang paliitin ng Universal Converter ang bawat larawan hanggang magkasya ito sa laking itinakda mo, o baguhin ito sa eksaktong pixel.

I-download para sa Mac Apple silicon, macOS 12 o mas bago · ✓ Walang nakitang virus (VirusTotal)
Paano mag-install at mag-update
  1. Buksan ang na-download na .dmg at i-drag ang Universal Converter sa Applications.
  2. Buksan ang app. Sa unang beses, ibo-block ito ng macOS dahil hindi ito pinirmahan ng Apple: i-click ang Done.
  3. Buksan ang System Settings > Privacy & Security, mag-scroll pababa, i-click ang Open Anyway at ilagay ang password mo. Isang beses mo lang ito gagawin.

Mga update: kung papayagan mo sa unang pagbukas ng app, titingin ito ng mga bagong bersyon tuwing magsisimula, ive-verify ang digital signature nila at ii-install ang mga ito kapag pinili mo.

I-download para sa Android Android 10 o mas bago · ✓ Walang nakitang virus (VirusTotal)
Paano mag-install at mag-update
  1. I-tap ang I-download para sa Android sa telepono mo.
  2. Buksan ang na-download na file. Kung magtanong ang Android, payagan ang browser o file manager mo na mag-install ng mga app.
  3. I-tap ang I-install.

Mga update: kapag binuksan mo ang app, titingnan nito kung may bagong bersyon at sasabihin sa iyo kapag handa na ito. I-download ito sa parehong paraan at i-install sa ibabaw ng luma; mananatili ang mga setting mo.

I-download para sa Linux 64-bit (x86_64): Ubuntu 22.04, Debian 12, Fedora 36 o mas bago · ✓ Walang nakitang virus (VirusTotal)
Paano mag-install at mag-update
  1. I-download ang .AppImage file.
  2. Gawin itong executable: i-right-click, buksan ang Properties > Permissions at payagang patakbuhin bilang program (o sa terminal: chmod +x Universal-Converter-*.AppImage).
  3. I-double-click ito. Walang ini-install: ang app ay ang iisang file na ito.

Mga update: kung papayagan mo sa unang pagbukas ng app, titingin ito ng bagong bersyon tuwing magsisimula, ive-verify ang digital signature nito at papalitan ang AppImage file kung nasaan ito.

Paano ito gawin

  1. Buksan ang Universal Converter.
  2. I-drag ang mga file mo o isang buong folder sa window, o i-click ang Magdagdag ng mga file.
  3. Lumipat sa Baguhin ang laki sa itaas at piliin ang pixel, porsyento o laki ng file.
  4. I-click ang I-convert. Sine-save ang mga bagong file katabi ng mga orihinal, o sa folder na pipiliin mo.

Bakit offline?

Ginagawa ng Universal Converter ang trabaho sa sarili mong device. Nananatiling pribado ang mga file mo, hindi problema ang malalaking file, at gumagana ito nang walang koneksyon sa internet.
