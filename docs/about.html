Universal Converter

About Universal Converter

Universal Converter is a free-to-use app for converting images, documents, videos and audio, building PDFs and pulling tables into Excel, all on your own device.

Why it works offline

The files people convert are often private: bank statements, contracts, ID scans, family videos. Universal Converter does all the work on your own device, so your files are never uploaded anywhere. There is no account, no advertising and no tracking in the app.

Who makes it

Universal Converter is designed and developed by Christos Tzouvaras, an independent developer. It is free to use and closed-source. Updates are digitally signed, so the app only installs versions that really come from the developer.

Where it runs

Windows 10 and 11 (also from the Microsoft Store), Mac with Apple silicon, 64-bit Linux and Android 10 or newer, in English, Greek, Spanish, Italian, German, French, Portuguese (Portugal and Brazil), Polish, Russian, Arabic, Hebrew, Simplified Chinese, Japanese, Korean, Tamil, Afrikaans, Yoruba, Hausa, Hindi, Indonesian, Turkish, Vietnamese, Swedish, Dutch, Danish, Ukrainian, Czech, Romanian, Bulgarian, Norwegian, Malay, Filipino and Swahili.

Help and contact

The guide explains each tool step by step. For questions, problems and ideas, email universal.converter@outlook.com; the privacy page explains exactly when the app goes online.

Supporting the project

Universal Converter stays free. If it saves you time, a voluntary contribution supports its further development and running costs.

Download for Mac Apple silicon, macOS 12 or later · ✓ No viruses found (VirusTotal)
How to install and update
  1. Open the downloaded .dmg and drag Universal Converter into Applications.
  2. Open the app. The first time, macOS blocks it because it isn't signed by Apple: click Done.
  3. Open System Settings > Privacy & Security, scroll down, click Open Anyway and enter your password. You only do this once.

Updates: if you allow it when the app first opens, it checks for new versions each time it starts, verifies their digital signature and installs them when you choose.

Download for Android Android 10 or later · ✓ No viruses found (VirusTotal)
How to install and update
  1. Tap Download for Android on your phone.
  2. Open the downloaded file. If Android asks, allow your browser or file manager to install apps.
  3. Tap Install.

Updates: when you open the app, it checks for a new version and tells you when one is ready. Download it the same way and install it over the old one; your settings are kept.

Download for Linux 64-bit (x86_64): Ubuntu 22.04, Debian 12, Fedora 36 or later · ✓ No viruses found (VirusTotal)
How to install and update
  1. Download the .AppImage file.
  2. Make it executable: right-click it, open Properties > Permissions and allow it to run as a program (or in a terminal: chmod +x Universal-Converter-*.AppImage).
  3. Double-click it. Nothing is installed: the app is this one file.

Updates: if you allow it when the app first opens, it checks for new versions each time it starts, verifies their digital signature and replaces the AppImage file where it is.
