Universal Converter

Kompres video tanpa mengunggahnya

Video ponsel dan rekaman layar sering jauh lebih besar dari yang diperlukan. Universal Converter meng-encode ulang dengan codec modern seperti H.265 dan AV1, sehingga jauh lebih hemat ruang dan tetap terlihat bagus.

Gratis · Windows 10 dan 11, 64-bit · ✓ Tidak ada virus (VirusTotal)Windows memblokir unduhan atau aplikasinya? Dapatkan dari Microsoft Store saja: aplikasi gratis yang sama, dan Windows memercayainya.
Unduh untuk Mac Apple silicon, macOS 12 atau lebih baru · ✓ Tidak ada virus (VirusTotal)
Cara memasang dan memperbarui
  1. Buka file .dmg yang diunduh dan seret Universal Converter ke Applications.
  2. Buka aplikasinya. Saat pertama kali, macOS memblokirnya karena tidak ditandatangani oleh Apple: klik Selesai.
  3. Buka Pengaturan Sistem > Privasi & Keamanan, gulir ke bawah, klik Tetap Buka, lalu masukkan kata sandi Anda. Ini hanya perlu dilakukan sekali.

Pembaruan: jika Anda mengizinkannya saat aplikasi pertama kali dibuka, aplikasi memeriksa versi baru setiap kali dimulai, memverifikasi tanda tangan digitalnya, dan memasangnya saat Anda memilih.

Unduh untuk Android Android 10 atau lebih baru · ✓ Tidak ada virus (VirusTotal)
Cara memasang dan memperbarui
  1. Ketuk Unduh untuk Android di ponsel Anda.
  2. Buka file yang diunduh. Jika Android meminta, izinkan browser atau pengelola file Anda memasang aplikasi.
  3. Ketuk Instal.

Pembaruan: saat Anda membuka aplikasi, aplikasi memeriksa versi baru dan memberi tahu Anda jika sudah siap. Unduh dengan cara yang sama dan pasang di atas versi lama; pengaturan Anda tetap ada.

Unduh untuk Linux 64-bit (x86_64): Ubuntu 22.04, Debian 12, Fedora 36 atau lebih baru · ✓ Tidak ada virus (VirusTotal)
Cara memasang dan memperbarui
  1. Unduh file .AppImage.
  2. Jadikan dapat dijalankan: klik kanan, buka Properti > Izin dan izinkan dijalankan sebagai program (atau di terminal: chmod +x Universal-Converter-*.AppImage).
  3. Klik dua kali. Tidak ada yang dipasang: aplikasinya adalah satu file ini.

Pembaruan: jika Anda mengizinkannya saat aplikasi pertama dibuka, aplikasi memeriksa versi baru setiap kali dimulai, memverifikasi tanda tangan digitalnya, dan menggantikan file AppImage di tempatnya.

Caranya

  1. Buka Universal Converter.
  2. Seret file atau seluruh folder ke jendela, atau klik Tambah file.
  3. Pilih MP4 dan geser penggeser kualitas ke bawah sampai ukurannya sesuai. Preset siap pakai untuk ponsel, web, dan pengarsipan siap membantu.
  4. Klik Konversi. File baru disimpan di samping file asli, atau di folder yang Anda pilih.

Mengapa offline?

Universal Converter mengerjakan semuanya di perangkat Anda sendiri. File Anda tetap privat, file besar tidak masalah, dan aplikasi berfungsi tanpa koneksi internet.
