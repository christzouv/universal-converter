Universal Converter

Πίνακες από PDF σε Excel

Το Universal Converter βρίσκει τους πίνακες σε κάθε σελίδα, ακόμη και σε σαρωμένες σελίδες και φωτογραφίες, που τις διαβάζει με αναγνώριση κειμένου (OCR). Οι αριθμοί μένουν αριθμοί, ώστε να τους αθροίσετε αμέσως.

Λήψη για Windows Δωρεάν · Windows 10 και 11, 64-bit · Έλεγχος για ιούς
Mac (beta) Apple silicon, macOS 12 ή νεότερο Android (beta) Android 10 ή νεότερο

Πώς γίνεται

  1. Ανοίξτε το Universal Converter και επιλέξτε Σε Excel στα αριστερά.
  2. Σύρετε τα αρχεία σας ή έναν ολόκληρο φάκελο στο παράθυρο, ή πατήστε Προσθήκη αρχείων.
  3. Επιλέξτε Excel (ή CSV). Για σαρώσεις, διαλέξτε τις γλώσσες του κειμένου ή αφήστε το αυτόματο.
  4. Πατήστε Μετατροπή. Τα νέα αρχεία αποθηκεύονται δίπλα στα αρχικά ή στον φάκελο που επιλέγετε.

Γιατί χωρίς internet;

Το Universal Converter κάνει τη δουλειά στον δικό σας υπολογιστή. Τα αρχεία σας μένουν ιδιωτικά, τα μεγάλα αρχεία δεν είναι πρόβλημα και λειτουργεί χωρίς σύνδεση στο internet.

Τι άλλο μπορεί να κάνει

  • Συμπίεση βίντεο χωρίς ανέβασμα
  • Μετατροπή MKV, MOV, AVI και WMV σε MP4
  • Αποθήκευση του ήχου ενός βίντεο σε MP3
  • GIF από βίντεο
  • Ένωση φωτογραφιών σε ένα PDF
  • Μετατροπή PDF σε Word
  • Ένωση πολλών αρχείων σε ένα PDF
  • Αντιγραφή του κειμένου από εικόνα (OCR)
  • Μετατροπή WEBP σε JPG ή PNG
  • Αλλαγή μεγέθους εικόνων ή μείωση σε μέγεθος αρχείου
