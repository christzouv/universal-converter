Universal Converter

Kontoauszug von PDF in Excel umwandeln

Kontoauszüge enthalten private Daten und sollten nicht auf eine Website hochgeladen werden. Universal Converter liest die Umsatztabellen auf Ihrem eigenen Gerät, auch aus gescannten oder fotografierten Auszügen, und hält Datum, Verwendungszweck und Betrag in eigenen Spalten, Beträge als Zahlen.

Für Windows herunterladenIm Microsoft Store
Kostenlos · Windows 10 und 11, 64 Bit · ✓ Keine Viren gefunden (VirusTotal)Windows blockiert den Download oder die App? Holen Sie sie aus dem Microsoft Store: dieselbe kostenlose App, der Windows vertraut.
Für Mac herunterladen Apple Silicon, macOS 12 oder neuer · ✓ Keine Viren gefunden (VirusTotal)
Installieren und aktualisieren
  1. Öffnen Sie die heruntergeladene .dmg-Datei und ziehen Sie Universal Converter in „Programme“.
  2. Öffnen Sie die App. Beim ersten Mal blockiert macOS sie, weil sie nicht von Apple signiert ist: Klicken Sie auf „Fertig“.
  3. Öffnen Sie Systemeinstellungen > Datenschutz & Sicherheit, scrollen Sie nach unten, klicken Sie auf „Dennoch öffnen“ und geben Sie Ihr Passwort ein. Das ist nur einmal nötig.

Updates: Wenn Sie es beim ersten Start erlauben, sucht die App bei jedem Start nach neuen Versionen, prüft ihre digitale Signatur und installiert sie, wann Sie möchten.

Für Android herunterladen Android 10 oder neuer · ✓ Keine Viren gefunden (VirusTotal)
Installieren und aktualisieren
  1. Tippen Sie auf dem Handy auf „Für Android herunterladen“.
  2. Öffnen Sie die heruntergeladene Datei. Wenn Android fragt, erlauben Sie Ihrem Browser oder Dateimanager, Apps zu installieren.
  3. Tippen Sie auf „Installieren“.

Updates: Die App prüft etwa einmal am Tag und meldet sich, wenn eine neue Version bereitsteht. Laden Sie sie genauso herunter und installieren Sie sie über die alte; Ihre Einstellungen bleiben erhalten.

Für Linux herunterladen 64 Bit (x86_64): Ubuntu 22.04, Debian 12, Fedora 36 oder neuer · ✓ Keine Viren gefunden (VirusTotal)
Installieren und aktualisieren
  1. Laden Sie die .AppImage-Datei herunter.
  2. Machen Sie sie ausführbar: Rechtsklick, Eigenschaften > Zugriffsrechte und das Ausführen als Programm erlauben (oder im Terminal: chmod +x Universal-Converter-*.AppImage).
  3. Doppelklicken Sie darauf. Es wird nichts installiert: Die App ist diese eine Datei.

Updates: Wenn Sie es beim ersten Öffnen erlauben, sucht die App bei jedem Start nach neuen Versionen, prüft ihre digitale Signatur und ersetzt die AppImage-Datei an ihrem Ort.

So geht's

  1. Öffnen Sie Universal Converter und wählen Sie links Dokumente & PDF.
  2. Ziehen Sie Ihre Dateien oder einen ganzen Ordner in das Fenster, oder klicken Sie auf Dateien hinzufügen.
  3. Wählen Sie Excel (oder CSV). Bei gescannten Auszügen wählen Sie die Sprache oder lassen es auf automatisch.
  4. Klicken Sie auf Konvertieren. Die neuen Dateien werden neben den Originalen gespeichert oder im gewählten Ordner.

Warum offline?

Universal Converter arbeitet auf Ihrem eigenen Gerät. Ihre Dateien bleiben privat, große Dateien sind kein Problem, und es funktioniert ohne Internetverbindung.
