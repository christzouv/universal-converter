Universal Converter

銀行の取引明細 PDF を Excel に変換

銀行の取引明細には個人情報が含まれるため、Web サイトにアップロードすべきではありません。Universal Converter はご自分のデバイス上で取引の表を読み取り、スキャンや写真の明細にも対応します。日付・摘要・金額をそれぞれの列に分け、金額は数値として保存します。

Windows 版をダウンロードMicrosoft Store から入手
無料 · Windows 10 / 11（64 ビット） · ✓ ウイルスは見つかりませんでした（VirusTotal）Windows がダウンロードやアプリをブロックしますか？ Microsoft Store から入手してください。同じ無料アプリで、Windows が信頼しています。
Mac 版をダウンロード Apple シリコン、macOS 12 以降 · ✓ ウイルスは見つかりませんでした（VirusTotal）
インストールと更新の方法
  1. ダウンロードした .dmg を開き、Universal Converter を「アプリケーション」にドラッグします。
  2. アプリを開きます。初回は Apple の署名がないため macOS にブロックされるので、「完了」をクリックします。
  3. 「システム設定」>「プライバシーとセキュリティ」を開いて下にスクロールし、「このまま開く」をクリックしてパスワードを入力します。これは最初の 1 回だけです。

更新：初回起動時に許可すると、起動のたびに新しいバージョンを確認し、デジタル署名を検証して、選んだタイミングでインストールします。

Android 版をダウンロード Android 10 以降 · ✓ ウイルスは見つかりませんでした（VirusTotal）
インストールと更新の方法
  1. スマートフォンで「Android 版をダウンロード」をタップします。
  2. ダウンロードしたファイルを開きます。Android に求められたら、ブラウザーまたはファイル管理アプリにアプリのインストールを許可します。
  3. 「インストール」をタップします。

更新：アプリを開くと新しいバージョンがあるか確認し、準備ができたらお知らせします。同じ方法でダウンロードして上書きインストールすれば、設定はそのまま残ります。

Linux 版をダウンロード 64 ビット (x86_64)：Ubuntu 22.04、Debian 12、Fedora 36 以降 · ✓ ウイルスは見つかりませんでした（VirusTotal）
インストールと更新の方法
  1. .AppImage ファイルをダウンロードします。
  2. 実行できるようにします。右クリックして［プロパティ］>［アクセス権］でプログラムとして実行を許可します（またはターミナルで：chmod +x Universal-Converter-*.AppImage）。
  3. ダブルクリックします。インストールは不要で、アプリはこの 1 つのファイルだけです。

アップデート：初回起動時に許可すると、起動のたびに新しいバージョンを確認し、デジタル署名を検証して、同じ場所の AppImage ファイルを置き換えます。

手順

  1. Universal Converter を開きます。
  2. ファイルやフォルダーをウィンドウにドラッグするか、「ファイルを追加」をクリックします。
  3. Excel（または CSV）を選びます。スキャンした明細は言語を選ぶか、自動のままにします。
  4. 「変換」をクリックします。新しいファイルは元のファイルの隣か、選んだフォルダーに保存されます。

なぜオフラインなのか

Universal Converter はご自身の端末で処理します。ファイルはプライベートなまま、大きなファイルも問題なく、インターネットがなくても使えます。

ほかにできること

  • PDF を Word に変換
  • Word 文書を PDF に変換
  • 複数のファイルを 1 つの PDF にまとめる
  • PDF を好きなサイズに圧縮
  • PDF を 100 KB・200 KB などオンラインフォームの指定サイズに圧縮
  • PDF のページを JPG 画像に変換
  • スキャンした文書を編集できる Word に変換
  • JPG、PNG、WEBP などの間で画像を変換
  • 画像のサイズ変更・ファイルサイズへの縮小
  • 写真や署名を 20 KB・50 KB や指定ピクセルにリサイズ
  • 写真を 1 つの PDF にまとめる
  • JPG を 100 KB 未満の PDF に
  • 画像の文字をコピー（OCR）
  • アップロードせずに動画を圧縮
  • MP4、MKV、WebM、MOV、AVI の間で動画を変換
  • 動画の音声を MP3 で保存
  • 動画から GIF を作る
  • PDF の表を Excel に取り出す
  • PDF の請求書から表を Excel に抽出
  • PDF に署名する
  • PDF フォームに入力する
