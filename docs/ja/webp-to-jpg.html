Universal Converter

JPG、PNG、WEBP などの間で画像を変換

Web サイトから保存した画像は WEBP のことが多く、開けないソフトもあります。Universal Converter は JPG、PNG、WEBP、TIFF、BMP、GIF、ICO の間で、たくさんのファイルを一度に変換します。

Windows 版をダウンロード Microsoft Store から入手
無料 · Windows 10 / 11（64 ビット） · ウイルススキャン結果
Mac 版をダウンロード（ベータ） Apple シリコン、macOS 12 以降
Android 版をダウンロード Android 10 以降

手順

  1. Universal Converter を開き、左側で画像を選びます。
  2. ファイルやフォルダーをウィンドウにドラッグするか、「ファイルを追加」をクリックします。
  3. 「変換先」で JPG（または PNG）を選びます。
  4. 「変換」をクリックします。新しいファイルは元のファイルの隣か、選んだフォルダーに保存されます。

なぜオフラインなのか

Universal Converter はご自身の端末で処理します。ファイルはプライベートなまま、大きなファイルも問題なく、インターネットがなくても使えます。

ほかにできること

  • アップロードせずに動画を圧縮
  • MP4、MKV、WebM、MOV、AVI の間で動画を変換
  • 動画の音声を MP3 で保存
  • 動画から GIF を作る
  • PDF の表を Excel に取り出す
  • 写真を 1 つの PDF にまとめる
  • PDF を Word に変換
  • 複数のファイルを 1 つの PDF にまとめる
  • 画像の文字をコピー（OCR）
  • 画像のサイズ変更・ファイルサイズへの縮小
  • 銀行の取引明細 PDF を Excel に変換
  • PDF の請求書から表を Excel に抽出
  • スキャンした文書を編集できる Word に変換
  • PDF のページを JPG 画像に変換
  • Word 文書を PDF に変換
