Universal Converter

Extraire les tableaux d'un PDF vers Excel

Universal Converter trouve les tableaux de chaque page, y compris les pages scannées et les photos, qu'il lit par reconnaissance de texte (OCR). Les nombres restent des nombres : vous pouvez les additionner tout de suite.

Télécharger pour Windows Obtenir dans le Microsoft Store Gratuit · Windows 10 et 11, 64 bits · Analyse antivirus
Mac (bêta) Apple silicon, macOS 12 ou ultérieur Android (bêta) Android 10 ou ultérieur

Comment faire

  1. Ouvrez Universal Converter et choisissez Vers Excel à gauche.
  2. Glissez vos fichiers ou un dossier entier dans la fenêtre, ou cliquez sur Ajouter des fichiers.
  3. Choisissez Excel (ou CSV). Pour les scans, choisissez les langues du texte ou laissez sur automatique.
  4. Cliquez sur Convertir. Les nouveaux fichiers sont enregistrés à côté des originaux, ou dans le dossier de votre choix.

Pourquoi hors ligne ?

Universal Converter travaille sur votre propre ordinateur. Vos fichiers restent privés, les gros fichiers ne posent pas de problème, et cela fonctionne sans connexion internet.
