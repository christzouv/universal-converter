Unire foto in un unico PDF

Utile per ricevute, pagine scansionate o un album di foto. Scegli formato pagina e margini, e ordina le immagini con le frecce accanto a ciascuna.

Scarica per Windows Scaricalo da Microsoft Store Gratis · Windows 10 e 11, 64 bit · Scansione antivirus
Mac (beta) Apple silicon, macOS 12 o successivo Android (beta) Android 10 o successivo

Come fare

  1. Apri Universal Converter e scegli Immagini a sinistra.
  2. Trascina i file o un'intera cartella nella finestra, oppure fai clic su Aggiungi file.
  3. Scegli PDF in Converti in, attiva «Unisci in un PDF» e imposta formato pagina e margine.
  4. Fai clic su Converti. I nuovi file vengono salvati accanto agli originali o nella cartella che scegli.

Perché offline?

Universal Converter lavora sul tuo computer. I tuoi file restano privati, i file grandi non sono un problema e funziona senza connessione a internet.
