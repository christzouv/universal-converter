Copiare il testo da un'immagine (OCR)

Il riconoscimento del testo (OCR) avviene sul tuo dispositivo. Le lingue con alfabeto latino e il greco vengono riconosciuti automaticamente (su Windows e Mac anche il cirillico); gli altri alfabeti si scaricano una volta, la prima volta che li scegli.

Scarica per Windows Scaricalo da Microsoft Store
Gratis · Windows 10 e 11, 64 bit · Scansione antivirus
Scarica per Mac (beta) Apple silicon, macOS 12 o successivo
Scarica per Android Android 10 o successivo

Come fare

  1. Apri Universal Converter e scegli Immagini a sinistra.
  2. Trascina i file o un'intera cartella nella finestra, oppure fai clic su Aggiungi file.
  3. Scegli TXT o DOCX in Converti in.
  4. Fai clic su Converti. I nuovi file vengono salvati accanto agli originali o nella cartella che scegli.

Perché offline?

Universal Converter lavora sul tuo dispositivo. I tuoi file restano privati, i file grandi non sono un problema e funziona senza connessione a internet.
