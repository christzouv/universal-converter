동영상으로 GIF 만들기

시작, 끝, 크기를 고르면 Universal Converter가 어디서나 재생되는 작은 GIF나 WebP 애니메이션을 만듭니다.

Windows용 다운로드 무료 · Windows 10, 11 (64비트) · 바이러스 검사 결과
Mac (베타) Apple 실리콘, macOS 12 이상 Android (베타) Android 10 이상

방법

  1. Universal Converter를 열고 왼쪽에서 동영상을(를) 선택하세요.
  2. 파일이나 폴더를 창으로 끌어다 놓거나 '파일 추가'를 누르세요.
  3. '변환 형식'에서 GIF를 고르고 시간 범위와 크기를 설정하세요.
  4. '변환'을(를) 누르세요. 새 파일은 원본 옆이나 선택한 폴더에 저장됩니다.

왜 오프라인인가요?

Universal Converter는 내 컴퓨터에서 작업합니다. 파일은 비공개로 유지되고, 큰 파일도 문제없으며, 인터넷 연결 없이도 작동합니다.

더 할 수 있는 일

  • 업로드 없이 동영상 압축하기
  • MKV, MOV, AVI, WMV를 MP4로 변환
  • 동영상의 소리를 MP3로 저장
  • PDF의 표를 Excel로 가져오기
  • 사진을 하나의 PDF로 합치기
  • PDF를 Word로 변환
  • 여러 파일을 하나의 PDF로 합치기
  • 이미지 속 글자 복사하기 (OCR)
  • WEBP를 JPG나 PNG로 변환
  • 이미지 크기 조정 또는 파일 크기로 줄이기
