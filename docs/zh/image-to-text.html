复制图片中的文字（OCR）

文字识别（OCR）在你的设备上进行。拉丁字母语言和希腊语会自动识别（在 Windows 和 Mac 上还包括西里尔字母）；其他文字在你第一次选择时下载一次。

操作步骤

  1. 打开 Universal Converter，在左侧选择图片。
  2. 把文件或整个文件夹拖入窗口，或点击“添加文件”。
  3. 在“转换为”中选择 TXT 或 DOCX。
  4. 点击“转换”。新文件会保存在原文件旁边，或保存到你选择的文件夹。

为什么离线处理？

Universal Converter 在你自己的设备上完成工作。文件保持私密，大文件也没问题，而且不联网也能用。
