Privacy policy

Last updated 5 November 2026. This applies to Universal Converter for Windows (including the Microsoft Store version), Mac and Android.

What Universal Converter collects

Nothing. The app has no account, no analytics, no advertising and no tracking. It does not collect, store or send any personal information.

Your files

Every conversion happens on your own device. The files you convert, and the results, are never uploaded anywhere.

When the app goes online

Only in these cases: (1) The Windows and Mac versions downloaded from this website check GitHub (api.github.com) for updates when they start; you can turn this off under Updates. The Android version does the same at most once a day (Settings > Updates). The Microsoft Store version does not: the Store installs its updates. (2) When you choose a text-recognition alphabet that isn't built in, its recognition model is downloaded once from ModelScope (www.modelscope.cn); the Android app downloads the interface languages you choose from this website. (3) The Android app, if you allow it (asked once, switch in Settings), sends anonymous error reports when something goes wrong: the error message with folder and file names removed, the app version, the phone model and the app language. They go to a private GitHub repository that only the developer can read. Like any web request, these let the server see your IP address; the app sends nothing else.

Links you open

Support, help and problem-report buttons open pages in your web browser (PayPal, Revolut, GitHub). Those sites' own privacy policies apply there. Universal Converter never sees or handles payment details.

What stays on your device

Your settings and a log file for troubleshooting are kept in your user folder (on Windows: %APPDATA%\Universal Converter) and are never sent anywhere. Uninstalling can remove them.

Contact

Questions about privacy: open an issue at https://github.com/christzouv/universal-converter/issues.
