Privacy policy

Last updated 12 November 2026. This applies to Universal Converter for Windows (including the Microsoft Store version), Mac and Android (including the Google Play version).

What Universal Converter collects

No personal information. The app has no account, no analytics, no advertising and no tracking. The only thing it can send is an anonymous error report when something goes wrong - and only if you allow it (see below).

Your files

Every conversion happens on your own device. The files you convert, and the results, are never uploaded anywhere.

When the app goes online

Only in these cases: (1) The Windows and Mac versions downloaded from this website check GitHub (api.github.com) for updates when they start; you can turn this off under Updates. The Android version does the same at most once a day (Settings > Updates). The Microsoft Store and Google Play versions don't: the store installs their updates. (2) When you choose a text-recognition alphabet that isn't built in, its recognition model is downloaded once from ModelScope (www.modelscope.cn). From version 3.1 all interface languages are built into the Android app; version 3.0 downloaded the ones you chose from this website. (3) If you allow it (each app asks once; there is a switch in Settings), the app sends anonymous error reports when something goes wrong: the error message with folder and file names removed, the type of file and the chosen conversion settings (never passwords or text you typed), the app version, the phone model (Android) or system version (Windows, Mac), and the app language. They go to a private GitHub repository that only the developer can read. Like any web request, these let the server see your IP address; the app sends nothing else. Reports are sent over an encrypted connection, kept only as long as needed to fix the problem, and deleted on request (email below). You can also send a report yourself by email from Settings.

Links you open

Support, help and problem-report buttons open pages in your web browser (this website, GitHub). Those sites' own privacy policies apply there; the support page links to PayPal and Revolut. Universal Converter never sees or handles payment details. The Microsoft Store and Google Play versions ask once whether you'd like to rate the app; that button opens the store.

What stays on your device

Your settings and a log file for troubleshooting are kept in your user folder (on Windows: %APPDATA%\Universal Converter) and are never sent anywhere. Uninstalling can remove them.

This website

The website uses GoatCounter to count visits: which page was opened, the site you came from, and the browser, screen size and country, worked out from your IP address, which is not stored. It uses no cookies and collects nothing that identifies you. Clicks on the download and support buttons are counted the same way.

Contact

Questions about privacy: email universal.converter@outlook.com, or open an issue at https://github.com/christzouv/universal-converter/issues.
